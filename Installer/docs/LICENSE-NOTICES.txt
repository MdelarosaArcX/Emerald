EMERALD DELTACAST SUITE

broadcast workstation does not have to have them installed and version-matched
separately. Those components remain under their own licences, reproduced or

4. .NET 8 runtime
-------------------------------------------------------------------------------
Location after install:  <install folder>\Launcher and

The launcher and the Deltacast capture service are published self-contained, so
each carries a private copy of the .NET 8 runtime. .NET is distributed by
Microsoft under the MIT licence.

-------------------------------------------------------------------------------
5. npm dependencies
-------------------------------------------------------------------------------
Location after install:  <install folder>\Emerald\backend\node_modules

The two Node backends ship their production dependency trees. Each package
keeps its own licence file inside its folder in node_modules; the great
majority are MIT, ISC or BSD licensed. A machine-readable inventory can be
produced from a build machine with:

    npm ls --omit=dev --all --json

6. Deltacast / VideoMaster SDK
-------------------------------------------------------------------------------
NOT BUNDLED.

The Deltacast capture service calls the VideoMaster runtime that ships with the
Deltacast SDI board's own driver package. That software is licensed by Deltacast
to the board's owner and is not redistributed here. Install the board driver
from Deltacast before expecting the capture service to open an SDI channel.
